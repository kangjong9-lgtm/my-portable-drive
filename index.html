My Portable Drive

사용자가 승인한 Google Drive 계정을 Windows 탐색기에서 개별 네트워크 위치로 사용하는 개인용 포터블 도구입니다.

기능

사용자가 직접 로그인한 계정의 폴더와 파일을 조회하고 다운로드하거나 업로드할 수 있습니다. 읽기·쓰기 연결에서는 사용자의 파일 관리 작업에 따라 수정·이동·삭제도 가능합니다. 자동 동기화나 미러링을 수행하지 않습니다.

작동 방식

사용자의 Windows PC에서 Rclone과 로컬 WebDAV 연결을 실행합니다. 이 웹사이트는 앱 소개와 정책 안내를 제공하며 Google 로그인이나 Drive 파일 업로드를 받지 않습니다.

Google이 제공하거나 보증하는 제품이 아닙니다. Google 계정은 Google의 인증 화면에서 직접 승인하며, 계정별 데이터와 설정을 분리해 관리합니다.

데이터와 권한
