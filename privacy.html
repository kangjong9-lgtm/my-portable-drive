개인정보처리방침

적용 대상: My Portable Drive. 시행일: 2026-10-16.

접근하는 데이터와 목적

사용자가 Google OAuth 화면에서 동의한 범위에서 Google Drive의 파일 이름, 폴더 구조, 파일 내용, 파일 속성, 저장용량 정보를 사용합니다. 계정 혼동 방지를 위해 계정 이메일 또는 식별자를 조회하고 그 해시를 로컬 설정에 저장합니다.

읽기 전용 권한은 파일 조회·다운로드에 사용합니다. 사용자가 승인한 전체 Drive 권한은 탐색기에서 파일 조회·생성·업로드·수정·이동·삭제를 처리하는 데 사용합니다. 자동 동기화·미러링은 하지 않습니다.

저장 위치와 보호

OAuth 클라이언트 정보, 접근 토큰, 갱신 토큰과 계정 설정은 사용자의 외장 저장장치 내 CONFIG 폴더에 보관하며 Windows 파일 권한으로 접근을 제한합니다. 이는 디스크 암호화가 아닙니다. 다른 PC의 관리자 접근까지 차단하지는 않습니다.

다운로드 파일, 시험 파일과 전송 사본은 사용자가 지정한 로컬 위치 또는 테스트 폴더에 저장될 수 있습니다. Windows WebDAV는 시스템 드라이브에 임시 캐시를 사용할 수 있습니다. 제어 로그는 오류 종류·연결 상태를 기록하며 비밀값을 기록하지 않도록 구성합니다. 로그는 파일별 크기와 회전·보존 기한을 제한합니다.

데이터 전달과 로컬 접근

인증 및 파일 전송을 위해 Google 서비스와 통신합니다. 앱은 광고·판매·AI 모델 학습 목적으로 Google 사용자 데이터를 이용하거나 제공하지 않습니다. 운영자가 별도로 운영하는 파일 중계 서버에 Drive 자료를 저장하지 않습니다.

현재 WebDAV는 127.0.0.1에만 연결되지만 별도 로컬 인증이 없으므로 같은 PC의 다른 프로그램과 사용자가 연결된 파일을 읽거나, 쓰기가 허용된 경우 변경할 수 있습니다. 신뢰할 수 있는 PC에서만 사용하세요.

보유 기간 및 접근 철회

로컬 인증 설정은 사용자가 제거할 때까지 보관됩니다. 사용자는 Google 계정의 연결 관리에서 앱 접근을 철회할 수 있습니다. 철회는 이미 내려받은 사본을 자동으로 지우지 않습니다. 연결 종료 후 불필요한 설정·캐시·다운로드 사본은 사용자가 관리하며, Google Drive 원본 삭제 여부도 사용자가 결정합니다.

웹사이트 호스팅

이 안내 사이트는 GitHub Pages에 게시됩니다. 로그인·분석 스크립트·입력 양식은 포함하지 않습니다. GitHub는 호스팅 제공자로서 접속 정보 등을 자체 개인정보처리방침에 따라 처리할 수 있습니다.

Google API 데이터 사용

My Portable Drive가 Google API에서 받은 정보를 사용하거나 다른 앱으로 전달하는 경우 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.
